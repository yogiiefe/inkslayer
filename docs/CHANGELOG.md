Replaced the sample-image application with a small Windows desktop game: procedural night district, title/menu, fixed-step AABB platforming, three health pips, one fire inspector, water handwriting and projectiles, elemental weakness, victory/death/retry, journal, pause/settings, strict/gentle stroke policies and optional debug overlay.

Preserved the Java/libGDX framework, existing runtime dependencies and original sample asset.

No final art/music, save system, Tiled pipeline, bosses, broad curriculum, campaign, commit or publishing was added. See TESTING for executed evidence and limitations.
